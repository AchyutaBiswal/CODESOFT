# Achyuta Calculator

A premium responsive scientific calculator built with HTML5, CSS3, and vanilla JavaScript for a CodSoft Level 1 Task 3 portfolio submission.

## Features

- Basic arithmetic: addition, subtraction, multiplication, division, decimals, percentage, and modulus.
- Scientific operations: square root, square, power, reciprocal, factorial, and absolute value.
- Memory tools: MC, MR, M+, and M-.
- Utility controls: C, CE, backspace, sign toggle, copy result, and keyboard input.
- Animated calculation history with clear and recall behavior.
- Dark and light themes with glassmorphism, neon accents, particles, hover glow, ripple effects, and responsive layouts.
- Error handling for division by zero, invalid factorials, invalid roots, and overflow.
- Scientific notation formatting for very large or very small values.

## Keyboard Shortcuts

- `0-9`: enter numbers
- `.`: decimal
- `+`, `-`, `*`, `/`, `^`: operators
- `%`: modulus
- `Enter` or `=`: calculate
- `Backspace`: delete one digit
- `Delete` or `C`: clear all
